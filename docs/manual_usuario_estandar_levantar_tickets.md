# Manual breve: levantar un ticket

Guía para usuarios estándar del Sistema de Tickets de Transportes Valadez.

## Crear una solicitud

1. Inicia sesión en el sistema con tu usuario y contraseña.
2. En el menú lateral, abre **Tickets → Crear**.
3. Verifica los datos que aparecen en pantalla: usuario, área y nombre. Se toman de tu cuenta.
4. En **Descripción del problema**, explica qué necesitas o qué falla. Este campo es obligatorio. Incluye, cuando aplique:
   - Qué estabas intentando hacer.
   - Qué ocurrió y qué mensaje apareció.
   - Desde cuándo sucede y si afecta a otras personas.
   - El equipo, programa o ubicación relacionada.
5. Si ayuda a explicar el caso, adjunta una imagen. Es opcional: puedes seleccionarla, arrastrarla al recuadro o pegarla con **Ctrl + V**.
6. Presiona **Enviar Ticket** una sola vez y espera la confirmación. El sistema analizará la descripción y asignará automáticamente el tipo de solicitud.

## Consultar el seguimiento

1. Abre **Tickets → Mis Tickets**.
2. Busca el ticket por su número y revisa el estado, la fecha de creación y la última actualización.
3. Abre **Abrir chat** para comunicarte con soporte sobre ese ticket. Revisa también los comentarios y archivos adjuntos del administrador.
4. Si el ticket sigue **Pendiente**, puedes cancelarlo desde esa misma vista.
5. Cuando el ticket esté finalizado, puedes seleccionar **Calificar** para compartir tu opinión.

## Para recibir ayuda más rápido

Escribe una solicitud por cada problema, describe los pasos con claridad y adjunta una captura si aparece un mensaje de error. No incluyas contraseñas ni otros datos confidenciales en la descripción o en las imágenes.
